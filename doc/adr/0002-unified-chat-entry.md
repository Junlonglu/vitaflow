# 统一对话入口替代独立功能 API

status: accepted
date: 2026-09-01

现有 AI 功能以独立 API/按钮形态暴露（生成/评分/润色/JD 优化/翻译/图片导入等 9 个入口），链路分散、部分功能实际使用率低，且「改地点」这类简单操作因整份简历重传延迟高达 30~50s。我们决定将简历对话升格为 AI 交互的统一入口：高频操作封装为对话内快捷指令（`/润色` `/翻译` `/优化` `/生成`，对应 pi-agent PromptTemplate），其余能力靠多模态自然对话触发；简历评分功能直接移除（单次 51s、独立价值低）。

## Considered Options

- **全部保留并 Agent 化**：单步结构化生成套 Agent 循环是负收益，拒绝。
- **试点性引入**（仅 resume-chat 迁移）：与「完全重写」的学习目标不符，拒绝。
- **统一对话入口**（采纳）：一次重写收敛所有入口，功能裁剪同步完成。

## Consequences

- LangChain/LangGraph 在迁移完成后直接退役，无兼容期（本设计文档即回滚依据）。
- `/优化` 指令承接原 LangGraph 8 节点 JD 优化场景，改为 Agent 多步工具调用——保留与 LangGraph 的对比学习素材。
- 前端独立功能组件（评分面板等）随之移除，AiChat 成为唯一 AI 界面。
